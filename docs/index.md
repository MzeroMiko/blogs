## Get Started Locally

To replicate this setup:

```bash
uv venv ~/venv/base --python 3.12
source ~/venv/base/bin/activate
uv pip install mkdocs-material mkdocs-static-i18n
mkdocs serve
```

> Browse the sidebar to explore the notes.
